# Security policy

## Supported versions

Only the latest release of each plugin receives security fixes. Releases are listed on the
[releases page](https://github.com/EBVN-Tech/churchcrm-plugin/releases), tagged
`<plugin-id>-v<version>`.

## Reporting a vulnerability

Report it privately through GitHub:
[Report a vulnerability](https://github.com/EBVN-Tech/churchcrm-plugin/security/advisories/new).
Do not open a public issue.

Include the plugin id and version, the affected route or hook, and the steps to reproduce.

## What happens next

- We acknowledge the report within 7 days.
- We confirm or dismiss it, and agree on a fix and disclosure date with you.
- We publish the fix as a new release, then a GitHub security advisory that credits you
  unless you ask otherwise.
- If a released plugin is listed in ChurchCRM's approved plugin registry, we also ask the
  ChurchCRM maintainers to drop or update its entry.
